เพศ : หญิง

เผ่า : แวมไพร์เลือดบริสุทธิ์

อายุ : 25 [ วันเกิด 12 กันยายน 1998 ]

น้ำหนัก/ส่วนสูง : - กก. / 164 ซม. (รวมรองเท้า)

-: เรื่องราว :-

- ในตอนเด็กๆเลย์อาศัยอยู่แต่ในคฤหาสน์ ด้วยความที่ยังเด็กและเป็นลูกคนเดียว ทำให้เธอไร้เพื่อนเล่นในวัยเดียวกัน เลย์จึงตัดสินใจแอบหนีออกไปเล่นกับพวกเด็กๆมนุษย์ในหมู่บ้านใกล้ๆ เธอปลอมตัวเป็นมนุษย์ไปเล่นกับพวกเด็กๆทุกวี่ทุกวัน จนกระทั่งอยู่มาวันนึง... ในขณะที่กำลังเล่นกับเด็กทั้ง 5 คนอยากสนุกสนาน จู่ ๆ ก็มีเด็กคนนึงเกิดหกล้ม และ มีแผลถลอกทำให้เลือดไหลออกมา เลย์ที่ในตอนนั้นยังเด็กจึงไม่สามารถควบคุมตัวเองได้ ด้วยสัญชาตญานแวมไพร์... เธอกระโจนเข้าใส่เด็กคนนั้นอย่างหิวกระหาย และเมื่อเลือดเข้าปาก เลย์ก็ไม่สามารถควบคุมตัวเองได้อีกต่อไป พอรู้ตัวอีกที... เด็กทั้ง 5 คนก็ได้จากโลกนี้ไปเสียแล้ว


ตั้งแต่เหตุการณ์นั้นมา...เลย์จึงไม่อยาก กินเลือดอีกต่อไป


- หลังจากตอนนั้น พอเลย์เลือกที่จะเลิกกินเลือด มันก็เป็นผลทำให้ร่างกายของเธอค่อยๆเปลี่ยนไปทีละนิดๆ และในตอนแรกๆแม้ว่าท่านพ่อกับท่านแม่จะไม่ถูกใจสักเท่าไหร่นักที่เห็นลูกสาวเพียงคนเดียวไม่ยอมกินเลือด แต่ก็ยังยอมนำอาหารของมนุษย์มาให้เธอกิน นั่นก็คือ KFC หากแต่พอนานวันเข้า เธอเริ่มรู้สึกว่าภายในคฤหาสน์นั้นเงียบเหงามากขึ้นทุกวัน เพราะท่านพ่อและท่านแม่เองก็ต้องออกไปทำธุระอยู่ตลอด จึงได้ตัดสินใจเปิดรับสมัครพ่อบ้าน / แม่บ้าน ผ่านทางช่องทางที่เรียกว่า โลกออนไลน์ นั่นเอง

[ ตอนกลางวัน ]

พละกำลัง = เปรียบได้กับผู้หญิงที่แสนจะอ่อนแอเปราะบางและแรงน้อยมาก วิ่งแปปเดียวก็เหนื่อยแล้ว ความเร็ว = วิ่งเร็วสุดได้พอๆกับมนุษย์ผู้หญิงที่ไม่ได้ออกกำลัง สมอง / สติปัญญา = วุฒิภาวะทางด้านอารมณ์ต่ำ / การคิดวิเคราะห์แยกแยะต่ำ / ความอดทนต่ำ / ความมั่นใจในตัวเองสูง / ความจำสั้น / ไม่สามารถเข้าใจคำพูดยากๆได้ ประสาทการรับรู้ = การมอง : เห็นเหมือนคนสายตาสั้น 2000+ / การได้ยิน : จะคล้ายหูอื้ออยู่ตลอดเวลาแต่ยังได้ยินเสียงคนพูดใกล้ๆอยู่ / การได้กลิ่น : คือถ้ากลิ่นไม่แรงจริงๆก็ต้องเข้าไปดมใกล้ๆ ( ยกเว้นกรณีที่กลิ่นของสิ่งๆนั้นคือเลือด สัญชาตญาณ​จะทำให้เลย์ได้กลิ่นเหมือนปกติ ) / การรับรู้รสชาด : ปกติ

[ Full Blood Nightmare ]

พละกำลัง = สามารถยกของหนัก 100 ตัน ( 100,000 กิโลกรัม ) ได้สบายๆ หรือประมาณวาฬสีน้ำเงินที่โตเต็มวัย ความเร็ว = เร็วได้สูงสุด 1 กิโลเมตร ต่อ 1 วินาที หรือเท่ากับ 3,600 กิโลเมตร ต่อ 1 ชั่วโมง และบินได้ด้วยความเร็วเท่ากัน
สมอง / สติปัญญา = วุฒิภาวะทางด้านอารมณ์ปกติ / การคิดวิเคราะห์แยกแยะมากกว่าปกติ / ความอดทนสูง / ความมั่นใจในตัวเองปกติ ( ไม่ประมาท ) / ความจำดี ประสาทการรับรู้ = การมอง : เห็นเหมือนคนปกติและสามารถมองเห็นในที่มืดได้ / การได้ยิน : ได้ยินเสียงหายใจในระยะ 5 กิโลเมตรโดยไม่ต้องใช้สกิล Echo location / การได้กลิ่น : ดีกว่าปกติ / การรับรู้รสชาด : ปกติ

-: พื้นฐานร่างกาย :-


-: ร่างแวมไพร์ :-

- ไม่จำเป็นต้องหายใจ แต่ยังสามารถรับรู้กลิ่นได้ และเหนื่อยได้เหมือนคนปกติ - ตัวเย็นตั้งแต่หัวจรดเท้า ทั้งภายในและภายนอก


-: เงื่อนไข :-

เวลากลางวัน / ไม่ได้ดื่มเลือด พลัง = 0 % : เลย์ ตอนเป็นหนมแทบจะไม่สามารถใช้พลังเวทย์ของเธอได้เลย และสมรรถภาพทุกอย่างจะติดลบ ทั้งพละกำลัง สติปัญญา เวลากลางคืน / ไม่ได้ดื่มเลือด & เวลากลางวัน / ได้ดื่มเลือด พลัง = 50 % : เลย์จะสามารถใช้พลังเวทย์ของเธอได้ปกติ ( สมรรถภาพทุกอย่างเท่ากับแวมไพร์เลือดบริสุทธิ์ยามกลางวัน ) เวลากลางคืน / ดื่มเลือด [ Full Blood Nightmare ] พลัง = 100 % : เลย์จะสามารถใช้เวทย์ที่แข็งแกร่งกว่าเดิมได้ และเสริมให้ศักยภาพทุกด้านดียิ่งขึ้น แข็งแกร่งขึ้น เร็วขึ้น พละกำลังมากขึ้น สติปัญญาเฉียบแหลมขึ้น ( สมรรถภาพทุกอย่างเท่ากับแวมไพร์เลือดบริสุทธิ์ยามกลางคืน )

[ ตอนกลางคืน ]

พละกำลัง = สามารถยกของหนัก 1 ตัน ( 1,000 กิโลกรัม ) ได้สบายๆ ความเร็ว = วิ่งเร็วสุดได้พอๆกับการปั่นจักรยาน และจะสามารถกระโดดได้สูงสุด 12 เมตรหรือประมาณ 1 เสาไฟฟ้า
สมอง / สติปัญญา = วุฒิภาวะทางด้านอารมณ์ปกติ / การคิดวิเคราะห์แยกแยะปกติ / ความอดทนปกติ / ความมั่นใจในตัวเองน้อย / ความจำปกติ
ประสาทการรับรู้ = การมอง : เห็นเหมือนคนปกติและสามารถมองเห็นในที่มืดได้ / การได้ยิน : ดีขึ้นเป็นอย่างมากถึงขั้นได้ยินเสียงหายใจในระยะ 1 กิโลเมตรได้โดยไม่ต้องใช้สกิล Echo location / การได้กลิ่น : ปกติ / การรับรู้รสชาด : ปกติ


-: ร่างค้างคาว :-

- มีระบบหายใจและการทำงานของร่างกายเหมือนสิ่งมีชีวิตทั่วไป
- ขนาดตัวเท่ากับ 1 ฝ่ามือ ( ไม่รวมปีก ) ตัวอุ่นมาก ( 40 องศา )
พละกำลัง = อิงจากพละกำลังในร่างแวมไพร์ ณ ช่วงเวลาตอนนั้น แต่จะเหนื่อยง่ายกว่ามาก
ความเร็ว = 500 เมตร ต่อ 1 วินาที หรือเท่ากับ 1,800 กิโลเมตร ต่อ 1 ชั่วโมง
สมอง / สติปัญญา / ประสาทการรับรู้ = อิงจากร่างแวมไพร์ ณ ช่วงเวลาตอนนั้น


-: พลังเวทย์ / อาวุธ โหมดปกติตอนกลางคืน :-


- การใช้สกิลนี้ต้องพูดออกมาเพื่อส่งคลื่นเสียงความถี่ออกไป เพียงแต่คลื่นชนิดนี้ไม่ได้ทำอันตรายต่อผู้ฟังเหมือน Scream of pain มันเป็นแค่การส่งออกไปเพื่อค้นหาตำแหน่งของวัตถุและตรวจสอบสภาพพื้นที่ในระยะเท่านั้น [ สามารถระบุตำแหน่งและพิกัดของทุกสรรพสิ่งได้ด้วยการปล่อยคลื่นเสียงออกไป แล้วคลื่นนั้นจะสะท้อนกลับมา ทำให้ได้ยินไม่ว่าสิ่งนั้นจะเป็นสิ่งไม่มีชีวิตหรือไม่ได้ขยับเขยื้อนอะไรเลยก็ตาม ขอแค่มีตัวตนให้คลื่นสามารถตกกระทบได้ก็เพียงพอ ]

[ Full Blood Nightmare ]

เลย์สามารถใช้อาวุธพร้อมกันได้ทั้ง 3 อย่าง ในโหมดนี้
ทั้ง 3 ชิ้น จะมีเพลิงประกายสีแดงที่สามารถแผดเผาทุกสิ่งครอบคลุมอยู่ด้วย
- ค้อน ทำให้แรงในการทุบอิงจากคนที่ใช้มันและเสริมแรงขึ้นไปอีก 10 เท่า
- กรรไกร จะสามารถควบคุมมันได้อิสระเหมือนกับกระดาษโดยไม่ต้องอาศัยมือจับอีกต่อไป
- กระดาษ จะให้แข็งหรืออ่อนก็ได้ แหลมคมยิ่งกว่าใบมีด หรือจะนำไปพันธนาการอีกฝ่ายให้เป็นมัมมี่ก็ได้ [ ไม่สามารถทำให้ขาดได้ ]
- ปีกค้างคาวจะกางออกมาโดยอัตโนมัติ / แปลงเป็นค้างคาวได้โดยไม่ต้องใช้สมาธิโฟกัส
- บัพฟื้นฟูขั้นสูง หากไม่โดนตัดหัวและทำลายทิ้งทันทีก็ยังสามารถนำมาเชื่อมต่อกลับได้อยู่
- ไร้จุดอ่อนทางกายภาพ ไม่แพ้ไฟ,ธาตุแสง,ธาตุศักดิ์สิทธิ์ หรือดีบัพอะไรก็ตามแต่ [ และยังคงไม่สามารถนำมาใช้ฮีลได้อยู่ดี ต้องใช้เลือดเท่านั้น ]
- อัพเกรดสกิล Echo location เป็นตรวจสอบทุกสิ่งในระยะ 1,000 กิโลเมตร
- สามารถใช้สกิล Scream of pain : ส่งคลื่นเสียงออกไปในระยะ 500 กิโลเมตร ทำอันตรายกับระบบประสาทการได้ยินของทุกสรรพสิ่ง ดาเมจจะขึ้นอยู่กับระยะการได้ยิน ( เลย์สามารถบังคับทิศทางของคลื่นเสียงนี้ได้ ดังนั้นในกรณีมีพันธมิตร​อยู่ในระยะ เลย์สามารถบังคับให้มันหลบเลี่ยงพวกเขาได้ )


[ ผลเอฟเฟคของแต่ละระยะการทำดาเมจ ]

~ 500 - 400 กิโลเมตร = ได้ยินเสียงเฉยๆ
~ 400 - 100 กิโลเมตร = หูอื้อ / หูหนวกชั่วคราว
~ 100 - 50 กิโลเมตร = สูญเสียการได้ยินไปตลอดชีวิต >> หูได้รับบาดเจ็บจนเลือดออก
~ 50 - 0 กิโลเมตร = สมองได้รับการกระทบกระเทือนจนสลบ >> ความจำเสื่อม

-: ท่าทาง :-

ค้อน : ยกมือทั้งสองข้างขึ้นมากุมกันไว้กลางหน้าอก ค้อนจะปรากฏมาเบื้องหน้าเป็นแนวนอน และ ลอยอยู่กลางอากาศ เปรียบเสมือนคทาเวทย์มนตร์ ต้องเอื้อมมือไปคว้า ไม่งั้นจะร่วงลงพื้น
- มือซ้ายจับไว้แถวๆปลายด้ามด้านล่างของค้อน ส่วนมือขวาจับไว้ตรงด้ามใกล้ๆส่วนหัว
กรรไกร : ยืดแขนขวาออกไปด้านข้างลำตัวจนสุด กรรไกรจะค่อยๆปรากฏขึ้นมาจากพื้น เริ่มจากส่วนหัวด้ามจับทั้งสอง จนกระทั่งด้านแหลมของมันปักตั้งตรงกับพื้นไว้ เปรียบเสมือนมีดดาบ รอการจับ
- กรณีขนาดใหญ่เท่าตัวเอง : มือขวาแบออก จับตรงกลางระหว่างห่วงด้านบนและด้านล่าง ก่อนจะยกขึ้นสะบัดปลายด้านแหลมออกจากตัวเอง ชี้ไปทางศัตรู
- กรณีขนาดเท่าปกติ : นิ้วชี้สอดไว้ห่วงด้านบน และนิ้วโป้งสอดไว้ที่ห่วงด้านล่าง
กระดาษ : ยกมือขวาขึ้นขนานกับพื้นเป็นมุม 90 องศา และเมื่อลงทัณฑ์ กำมือที่แบอยู่เข้าหากัน
- กระดาษต้องเตรียมมาเอง

-: ข้อมูล :-


- ชอบตอนกลางคืน เกลียดตอนกลางวัน เพราะมันร้อนและมีผลกับศักยภาพของเลย์มากๆ
- จริงๆแวมไพร์มีพฤติกรรมอาศัยอยู่รวมกันเป็นฝูงขนาดใหญ่เฉกเช่นเดียวกับค้างคาว แต่เพราะเลย์ต้องอยู่คนเดียวมาโดยตลอดจึงกลายเป็นเข้ากับคนอื่นๆยาก
- ในน้ำลายเลย์จะมีเอนไซม์ทำให้เลือดไม่แข็งตัว สะดวกต่อการกัดกิน
- ใช้การฟังเสียงแทนการมอง ถ้าหากเกิดตาบอดขึ้นมา เธอสามารถใช้หูในการมองเห็นแทนได้ / แต่ถ้าหากทำให้หูได้รับอันตราย จะทำให้สูญเสียการรับรู้ที่ดีที่สุดเลยทันที


-: ข้อเท็จจริง :-

- น้ำลายของค้างคาวมีเอนไซม์ที่มีโปรตีนชื่อ ดราคูลิน (Draculin) ที่ยับยั้งการทำงานของแฟคเตอร์ 10 (Factor X) ทำให้เลือดไม่หยุดไหล
- ค้างคาวแวมไพร์ จะกัดเหยื่อแล้วเลียเลือดที่หยดออกมา (ไม่ได้ดูดเลือดอย่างแวมไพร์ในนิยายหรือภาพยนตร์)
- ค้างคาวเป็นสัตว์ปีกที่เสียงดังที่สุดในโลก หรือ แม้แต่เทียบกับสัตว์บก ก็เป็นอันดับ 1
- คลื่นเสียงของค้างคาว ดังเกินกว่าที่มนุษย์จะได้ยิน เสียงที่ทำอันตรายต่อมนุษย์ได้คือเสียงที่ความดัง 120 เดซิเบล (dB) แต่ค้างคาวจะส่งเสียงได้ดังที่สุดถึง 140 เดซิเบล (dB) คุณสมบัติพิเศษคือสามารถส่งเสียงและรับเสียงที่สะท้อนกลับได้ ค้างคาวจะส่งเสียงร้องที่เรียกว่า "เสียงอุลตราโซนิก" (เสียงที่มีความถี่สูงมากกว่า 20 kHz) คลื่นเสียงอุลตราโซนิกนี้จะสะท้อนกลับมาเมื่อไปกระทบสิ่งกีดขวาง สมองของค้างคาวจะแปลความหมายและสามารถบอกได้ว่าคลื่นเสียงที่มันเปล่งออกไปนั้นไปกระทบกับอะไร เหยื่อหรือศัตรู รูปร่างเป็นยังไง อยู่ห่างออกไปแค่ไหน ทิศทางใด และเคลื่อนที่ด้วยความรวดเร็วเพียงใด ระบบการส่งเสียงและรับเสียงของค้างคาวนี้ นักวิทยาศาสตร์เรียกว่า "เอโคโลเคชั่น" (Echo-location)
: แมวสามารถได้ยินเสียงที่มีความถี่ระหว่าง 60 - 65,000 เฮิรตซ์ :

- มนุษย์เสียเลือดเท่าไหร่ถึงจะตาย : โดยปกติปริมาณเลือดในร่างกายมนุษย์จะมีอยู่ 5000 cc. ( การเสียเลือด - คนเราอาจรอดตายได้ หากเสียเลือดไป 30% แต่หากเสียเลือดถึง 40% ก็จำเป็นต้องได้รับการให้เลือดอย่างทันที ก่อนจะเสียชีวิตเพราะอาการช็อคฉับพลัน ) [ เมื่อเราเสียเลือดไป 10 % คือ ประมาณ 500 cc (0.5 ลิตร) จะอยู่ระยะเกือบช๊อค (Impending shock) / เมื่อเราเสียเลือดไป 20 % คือ ประมาณ 1000 cc (1 ลิตร) จะเข้าสู่ระยะช๊อค ] เสีย 10% > เริ่มช็อค แต่พอมีโอกาสรอด
เสีย 20% > ช็อค แต่พอมีโอกาสรอด
เสีย 30% > ช็อคหนักมาก แต่พอมีโอกาสรอด
เสีย 40% > ช็อคหนักมาก และต้องรับเลือดอย่างทันที อาจยังพอมีโอกาสรอด
มากกว่า 40% หรือเกินกว่า 4 ลิตร (4000 cc.) = ตายทันที
1 ลิตร = 1000 cc. / ml. (cc. กับ ml. มีค่าเท่ากัน)
- รูปแบบอาการต่างๆเมื่อเสียเลือด :
1.อาการจากอวัยวะที่เสียเลือดหรือเสียน้ำ เช่น กรณีกรีดมือ จะเจ็บปวดทรมาน อาจตัดเส้นประสาททำให้มือทำงานไม่ได้เป็นทุพพลภาพไปเลยก็ได้ เป็นต้น
2.สมอง ซึม หรือ สับสน อาละวาด ง่วง และเมื่อรุนแรงจนถึงไม่มีเลือดไปเลี้ยงสมองแล้วก็จะโคม่าสะลึมสะลือ​เรียกไม่ตื่นหรือขาดสติไปเลย
3.หัวใจ ใจสั่น หวิววูบ ลอย หอบ หายใจไม่สะดวก เจ็บอก ใจเต้นแรง เต้นเร็ว ถึงจุดหนึ่ง หัวใจจะเต้นช้าลงหรือหยุดเต้นได้
4.อาการผิวหนังขาดเลือด จะเป็นจ้ำเลือดไม่สม่ำเสมอ ซีด มือเท้าเย็น มือเท้าเขียว เหงื่อออก หรือร้อนหนาวผิดปกติไป เล็บซีดลง หรือ กดแล้วเลือดแดงที่เลี้ยงเล็บแดงขึ้นช้ากว่าปกติ (ลองกดปลายเล็บแล้วปล่อย จะมีสีแดงขึ้นช้าลง)
5.อาการจากระบบประสาทอัตโนมัติ จะขนลุก ร้อนหนาว วูบวาบ เหงื่อออกรูขุมขน
